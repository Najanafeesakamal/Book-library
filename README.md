# Book Library Collection

A React app showcasing a collection of books using reusable components, built with Vite.

## Components
- **BookCard:** Reusable component to display individual book information.

## Links
- **GitHub Repository:** https://github.com/yourname/book-library
- **Live Website:** https://yourprojecturl.vercel.app/

## Run Locally
1. Clone the repository  
2. Run `npm install`  
3. Run `npm run dev`

## Features
- Header section  
- Reusable BookCard component  
- Book list using map()  
- Summary section (total books + common genre)  
- Footer with developer info
